RBE 550

Task and Motion Planning with Genesis

Built a full TAMP pipeline for a Franka Panda manipulator using PDDL-based task planning (Pyperplan) and OMPL for motion planning. The robot picks and places colored blocks into multi-goal structures including a pentagon arrangement, with anti-drift PD control for stability during manipulation.

Python OMPL Pyperplan Genesis Sim PDDL
CS 551

Hierarchical RL for Robot Navigation

Implemented a hierarchical reinforcement learning system in Habitat 2.0 for indoor robot navigation. A high-level policy selects subgoals while a low-level PPO policy handles point-to-point navigation. Tuned entropy coefficients to resolve policy collapse during training.

Python PyTorch PPO Habitat 2.0
RBE 501

Robot Dynamics Simulation

Full dynamics simulation pipeline in MATLAB for multiple robot systems (3-DOF arm, UR5, custom 6-DOF). Implemented inverse dynamics control, forward dynamics integration via Newton-Euler, and trajectory following using the Product of Exponentials formulation.

MATLAB Screw Theory Newton-Euler PoE
RBE 502

Nonlinear Robot Control

Implemented and analyzed various nonlinear control strategies: Lyapunov stability proofs, LaSalle's Invariance Principle, controllability via Lie brackets, unicycle tracking control, and null-space projection for differential kinematics of redundant manipulators.

MATLAB Lyapunov Lie Brackets LaTeX
RBE 500

OpenManipulator-X Control

End-to-end control pipeline for the OpenManipulator-X in ROS2. Implemented forward/inverse kinematics using DH parameters, velocity kinematics via the Jacobian, and PD joint-space control for trajectory tracking.

ROS2 Python FK / IK Jacobian
